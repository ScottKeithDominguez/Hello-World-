## Security & Code Quality

This repository is configured with:
- **CodeQL Analysis**: Automated security scanning for JavaScript/TypeScript, Python, Go, and Java
- **Development Container**: Pre-configured environment for CodeQL development

See [SECURITY_SETUP.md](SECURITY_SETUP.md) for detailed security configuration instructions.

## Development Environment

A development container is available at `.devcontainer/devcontainer.json` with:
- CodeQL container image
- Pre-installed tools: Node.js, Python, Go, Java, GitHub CLI
- VS Code extensions for CodeQL development

To use the devcontainer:
1. Open this repository in VS Code
2. Install the "Dev Containers" extension
3. Click "Reopen in Container" when prompted
